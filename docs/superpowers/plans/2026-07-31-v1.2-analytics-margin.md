# v1.2 Analytics de Margen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a margin analytics dashboard for the owner to track real profit by crossing sales with denormalized cost data from purchase orders.

**Architecture:** Denormalize `last_cost_cents` into the `Product` collection during the receiving transaction. Use a hierarchical fallback (`last_cost_cents` -> `price_cents/2`) for historical data. Aggregate all calculations in a new `marginService.ts` on the client side.

**Tech Stack:** React 18, TypeScript, Firestore, Recharts.

## Global Constraints

- All monetary values in centavos (`*_cents`) as per `AGENTS.md`.
- UI language: Spanish (ES-CO).
- Use `formatCurrency` and `formatNumber` from `reportService.ts`.
- Hierarchical fallback: `last_cost_cents` -> `price_cents / 2` -> `0`.
- Access control: Only `admin` role can see the Margins page.

```typescript
import { Product } from '../firebase/db';

export function resolveCost(product: Product): { costCents: number; isEstimated: boolean } {
  if (product.last_cost_cents !== undefined && product.last_cost_cents !== null) {
    return { costCents: product.last_cost_cents, isEstimated: false };
  }
  if (product.price_cents !== undefined) {
    return { costCents: Math.floor(product.price_cents / 2), isEstimated: true };
  }
  return { costCents: 0, isEstimated: false };
}
```
