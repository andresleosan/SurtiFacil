# v1.3 Reposición Predictiva Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a predictive restocking page that suggests what to order, how much, and from which supplier based on sales velocity, current stock, and supplier lead time.

**Architecture:** Add `lead_time_days` field to `Supplier`. Create `restockService.ts` that joins sales, products, and suppliers in client memory with hierarchical fallback (product velocity → category average → insufficient). Render results in a new `Restock.tsx` page accessible only to admin/manager, with the existing `PurchaseOrderModal` extended to accept pre-filled items.

**Tech Stack:** React 18, TypeScript, Firestore, Recharts (not used in this version), Tailwind.

## Global Constraints

- All monetary values in centavos (`*_cents`) per AGENTS.md.
- UI language: Spanish (ES-CO).
- Use `formatCurrency` from `reportService.ts`.
- Hierarchical fallback for velocity: `product` → `category_avg` → excluded (`insufficient`).
- Hierarchical fallback for cost: `last_cost_cents` → `price_cents / 2`.
- Access control: only `admin` and `manager` can see the Restock page; render guard mandatory (not only nav guard).
- No emojis in files (user requirement).
