**Date:** 2026-07-31
**Author:** Cronos
**Status:** Approved

## Goal

Add barcode scanning capability across multiple screens (Inventory, CreateSale, AddProductModal) and convert the app to a Progressive Web App with installable support and offline caching.

---

## Scope

| Feature | Description |
|---------|-------------|
| Barcode Scanner | Reusable component using `html5-qrcode` library |
| PWA Installable | Manifest + icons + install prompt |
| PWA Offline | Workbox caching for critical assets and data |

---

## Architecture

### Data Model Changes

**File:** `web/src/firebase/db.ts`

```typescript
export interface Product {
  // ... existing fields
  barcode?: string;  // EAN-13, UPC-A, or QR code
}
```

Firestore migration: Add `barcode` field to existing products (optional, backward compatible).

### New Components

| Component | Path | Props | Description |
|-----------|------|-------|-------------|
| `BarcodeScanner.tsx` | `web/src/components/` | `onScan: (code: string) => void, onClose: () => void` | Modal with camera, detects code, returns result |
| `useBarcode.ts` | `web/src/hooks/` | `onScan: (code: string) => void` | Hook managing scanner state |

### Modified Components

| File | Changes |
|------|---------|
| `db.ts` | Add `barcode?: string` to `Product` |
| `Inventory.tsx` | "Scan" button + barcode column in table + field in edit modal |
| `CreateSale.tsx` | "Scan" button that auto-selects product by barcode |
| `AddProductModal.tsx` | "Scan" tab to pre-fill barcode when creating product |

## Integration Flows

### CreateSale Flow

```
1. Click "Escanear" → Opens camera modal
2. User points to barcode
3. html5-qrcode detects code (EAN-13/UPC-A/QR)
4. onScan(barcode) → closes modal
5. Search product in Firestore by barcode
6. If exists → auto-select in dropdown, add to cart
7. If not → show toast "Product not found"
```

### Inventory Flow

```
1. Click "Escanear" → Opens camera modal
2. Detects code → onScan(barcode)
3. Search product by barcode
4. If exists → opens edit modal with pre-filled data
5. If not → ask "Create product with this code?"
6. If yes → opens AddProductModal with pre-filled barcode
```

### AddProductModal Flow

```
1. Click "Escanear" tab → Opens camera modal
2. Detects code → onScan(barcode)
3. Pre-fills barcode field in form
4. User completes name, price, etc.
5. Saves product with barcode included
```

## Error Handling

| Scenario | UI |
|----------|-----|
| Camera not available | Toast "Camera not available. Use manual input." |
| Permission denied | Toast "Camera permission denied." |
| Code not detected | Scanner stays active, user can retry |
| Product not found (sale) | Toast "Code not registered. Add product first." |
| Offline | PWA cache serves data, scanner works (camera is local) |


### Offline Strategy (Workbox)

| Resource | Strategy | Reason |
|----------|----------|--------|
| `index.html` | Network First | Always try fresh, fallback to cache |
| `assets/*.js, *.css` | Cache First | Immutable assets by hash |
| `api/products` | Network First + Cache | Critical data, offline fallback |
| `api/sales` | Network Only | Transactional data, don't cache |

### Dependencies

```bash
npm install vite-plugin-pwa workbox-window
```
